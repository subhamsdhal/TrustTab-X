# M5 local decision-support architecture

`trusttabx.m5_train` loads the bounded Folktables ACSIncome 2018 source-state sample using the existing `acs_domain` adapter. Existing split logic separates fit, source selection, calibration audit, IID test and geographic OOD test. Five fixed classical candidates fit only on fit rows with fit-only preprocessing; minimum source-selection Brier chooses one pipeline. The calibration partition is audited, not used to tune an abstention or probability map. The final IID/OOD labels remain outside M5 training.

The offline trainer writes a versioned JSON manifest and the selected fitted sklearn pipeline to an ignored local bundle. Manifest validation checks feature order/types, schema and model versions, sklearn version, and model SHA256 before loading. SHA256 detects corruption but does not authenticate an attacker-controlled manifest; `TRUSTTABX_TRUST_LOCAL_ARTIFACT=1` is an explicit local operator trust gate. Do not load bundles received from untrusted sources.

At startup FastAPI validates distinct operator/admin keys and an operator-approved manifest digest, then loads the pipeline once. Pydantic validates each record and caps prediction batches at 100. Authenticated inference returns the fixed expert probability, a versioned threshold-0.5 class, no abstention, and an audit ID. No adaptive router is active. A request guard bounds body size and processing time; a per-process sliding window limits key use. In-memory telemetry stores only aggregate latency and probabilities; structured audit logs contain no raw features, labels, probabilities or secrets. `/monitor/drift` compares supplied ACS-shaped records against source-fit summary statistics. Admin-only `/monitor/delayed-labels` computes offline metrics when aligned labels and probabilities are supplied. The dashboard fetches these endpoints after the operator supplies a key held only in browser-tab memory. See [M5.1 security policy](M5_SECURITY.md).

Docker Compose supplies a loopback-only port, read-only bundle mount, nonroot process, read-only filesystem, tmpfs, health check and 2 GiB/2 CPU limits. Its service-only dependency set and artifact package versions use pinned `constraints/m5.txt`; the loader fails on a different sklearn version. A synthetic container verification script and manual CI workflow are available; Docker build/run is pending an available Docker engine.

This system is a portfolio-grade local research demonstrator with API-key authorization. It has no TLS or centralized identity, durable audit store, enforced external log retention, real traffic source, deployment approval, or security review for external use. ACS survey features may be sensitive and source-data rights require review before redistribution or real decision use.
