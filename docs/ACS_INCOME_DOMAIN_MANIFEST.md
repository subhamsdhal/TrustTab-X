# ACSIncome geographic pilot manifest (2026-10-20)

This is a **TableShift-inspired** benchmark, not an official TableShift score. The official [TableShift `acsincome` configuration](https://github.com/mlfoundations/tableshift/blob/main/tableshift/configs/benchmark_configs.py) defines New England (`DIVISION == 01`) as OOD; its [ACS task source](https://github.com/mlfoundations/tableshift/blob/main/tableshift/datasets/acs.py) uses 2018 ACS 1-year person PUMS, the Folktables adult filter and `PINCP > $56,000`. [Folktables ACSIncome](https://github.com/socialfoundations/folktables) ordinarily uses `$50,000`, so this runner fixes the TableShift threshold explicitly. Data originate from the [US Census 2018 ACS PUMS release](https://www.census.gov/programs-surveys/acs/microdata/access/2018.html). Folktables code is MIT licensed; underlying Census data have separate [Census usage and privacy terms](https://www.census.gov/data/developers/about/terms-of-service.html). No raw records are committed or published.

## Preregistered bounded protocol

- Source: PA, NJ, NY, OR, NM, KS, AL; five Census divisions. Target: CT, MA, ME, NH, RI, VT; all six New England states. Each state is an environment, but states within one division and survey are correlated. The official TableShift source includes many more states and uses different row splits and a broader feature set.
- Sample without outcome stratification after the adult task filter: 6,000 eligible people per source state and 3,000 per target state, fixed seed 264738 plus a deterministic state-code offset. The adult filter requires `AGEP > 16`, `PINCP > 100`, `WKHP > 0` and `PWGTP >= 1`. The source training cap is 14,000, sampled as whole households with 2,000 rows per state. OOD labels are only scored and audited after source-based selection.
- Source fit, selection, calibration and ID test are disjoint by `state:SERIALNO` household group. All six OOD states are untouched final tests. The 10 predictors are `AGEP`, `WKHP`, `COW`, `SCHL`, `MAR`, `OCCP`, `POBP`, `RELP`, `SEX`, `RAC1P`. `PINCP`, state, division, household ID, PUMA and survey weight are excluded as predictors. The task filter's use of `PINCP > 100` is part of the published population definition. Sampling is unweighted; these scores are not representative population estimates. Demographic attributes are present and this is research evaluation, not an employment or lending service.
- All numeric imputation, scaling and categorical imputation/one-hot encoding are fit within each training pipeline. Source selection Brier chooses the expert; a separate source calibration set sets conformal thresholds. Five fixed expert configurations are fit once for a shared-cost 3-vs-5 candidate comparison. A separate three-model fit measures actual smaller-pool training cost. There are no tuning trials. CPU execution used one BLAS/OpenMP thread.

The final run is `outputs/acs_income_2018_geographic_expanded.json`, with an aggregate-only tracked copy at `reports/results/acs_income_2018_geographic_expanded.json`; it records every state’s raw, eligible and sampled counts, final-audit prevalence, source-file SHA-256, sample-index SHA-256, split hashes, package versions, model selection scores, prediction diversity, fit/inference time, Windows peak process working set and ID/OOD metrics. The initial three-source-state smoke/pilot files remain local and ignored. Reproduce with `./.venv/Scripts/trusttabx.exe acs-benchmark --max-fit-rows 14000 --output outputs/acs_income_2018_geographic_expanded.json` after `pip install -e '.[benchmarks,acs,dev]'`. Raw Census files are cached under the ignored `data/raw/acs2018` directory.

## Final run and limits

The final bounded run fitted 14,000 source rows; selection 4,193; calibration 4,200; ID test 4,240; OOD test 18,000 (3,000 in each target state). Source-state sampled positive rates ranged from 0.262 to 0.440; OOD-state rates ranged from 0.252 to 0.434. Both selectors chose HistGradientBoosting. ID/OOD Brier was 0.131644/0.145517; log loss 0.406822/0.441380; AUROC 0.872832/0.860965; AUPRC 0.743474/0.760401; 10-bin ECE 0.024424/0.006536. The ID-to-OOD Brier change was +0.013873 and log-loss change +0.034557. The two candidate sets have identical predictive outcomes; additional experts did not help here. AUPRC changes with prevalence and is not a prevalence-matched comparison. State Brier scores were CT 0.151473, MA 0.150411, ME 0.133495, NH 0.144196, RI 0.148547 and VT 0.144981. No confidence interval is claimed from one survey year and one held-out division.

The final local run recorded 5.132 seconds for the shared five-model fit pool and 2.061 seconds for a separately refitted three-model pool. The latter's ID/OOD Brier was identical to the shared three-candidate decision. Selected-model inference took 0.043/0.197 seconds on 4,240 ID/18,000 OOD rows in the shared pool and 0.054/0.228 seconds after separate refitting; local wall-clock timing varies. The peak Windows process working set was 1,317,712 KiB. These are single-run CPU measurements, not hardware-independent costs.
