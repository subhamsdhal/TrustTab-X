# ACSIncome model artifact and monitoring

The M5 artifact is task-specific: ACSIncome 2018, 10 ordered features, source states PA/NJ/NY/OR/NM/KS/AL, 14,000 bounded fit rows, 4,193 selection rows, and 4,200 calibration audit rows. Seed: 264738. Selected expert: histogram gradient boosting, by source-selection Brier 0.1357396620 among five fixed candidates. Source calibration Brier: 0.1411259448. This is not a fresh final-target estimate. Prior locked M4.2 result is decision C, **no adaptive advantage demonstrated**. Routers remain research-only.

`outputs/m5_acs_model/manifest.json` records the task and target mapping, ordered features and types, model/schema versions, data and split SHA256 values, seed, selected model and all source-selection scores, source calibration metrics, fit duration, working-set observation, package version, reference distributions and pipeline SHA256. The `.joblib` contains the fitted preprocessing and model together. Both are ignored by Git because they are local artifacts; no raw ACS rows are bundled. Optional MLflow 3 records source parameters and aggregate metrics to local SQLite `mlflow.db` in the same ignored directory. The manifest itself is the portable registry record; there is no hosted registry.

`/monitor/drift` uses source-fit means/SD for AGEP and WKHP and categorical total variation (TV = 1/2 sum of absolute category-frequency differences). Heuristic alert cutoffs are standardized numeric mean shift >1, categorical TV >0.2 or unseen category, and mean predicted-probability shift >0.1. These are diagnostic demonstration cutoffs, not calibrated false-alarm guarantees. Tiny monitoring samples can naturally exceed them. The dashboard explicitly labels its one-record inspection illustrative. Missing/malformed inputs fail validation; unknown categories fail prediction validation. Service telemetry counts successful predictions and inference errors and keeps bounded latency/probability windows in memory. It resets on restart and has no durable production observability.

Feature or probability drift does not establish a loss of predictive performance. Without delayed labels the realised Brier, calibration and accuracy are unknown. `/monitor/delayed-labels` computes Brier, log loss, AUROC/AUPRC when both classes occur, and 10-bin ECE for a supplied aligned offline cohort. This endpoint is an analysis helper, not a claim that caller-supplied labels are authentic. There is no automatic switching, abstention, retraining, or shift correction. Operational review is required before responding to a drift alert.
