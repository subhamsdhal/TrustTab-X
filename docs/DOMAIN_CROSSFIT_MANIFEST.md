# Source-only domain cross-fitting and exploratory router gate (2026-10-21)

The reusable `domain_holdout_plan` excludes reserved/final row indices before generating source folds. ACS uses leave-one-source-state-out fits on seven household-disjoint states (35 model fits, 14,000 held-out predictions); hospital uses four patient-disjoint source admission codes 1/17/4/6 (20 fits, 22,472 predictions); bank uses three forward-only held-out blocks inside the earliest fit window (15 fits, 15,445 predictions). Total: **14 source folds, 70 expert fits, 51,917 held-out source predictions**. Fold summaries are tracked in `reports/results/*_source_crossfit.json`. The row-level cross-fit prediction archives remain ignored under `data/processed/` because they contain source labels and survey/health prediction metadata. ACS source folds are states within one survey, so they are not independent dataset replicates. The bank blocks are chronological, not IID.

The [locked exploratory router protocol](ROUTER_PROTOTYPE_PREREGISTRATION.md) uses 12 comparable expert-probability metadata values; it never concatenates incompatible raw predictor columns. Five regularised squared-error models fit on cross-domain source predictions with equal total weight per family and environment. Within each family, source selection determines the fixed expert and ensemble weights, and separate source calibration determines conformal and 80%-target decision thresholds. Final-domain labels are used only for the result file. Router fit took 0.200 s after cross-fit predictions were generated; this excludes the substantial five-expert and cross-fit costs, which are recorded separately.

The router did not beat the fixed expert on Brier in any family. The bank uniform ensemble improved on the fixed expert in that particular future window. Router AURC was 0.092183/0.382299/0.362349 for ACS/hospital/bank versus static 0.088882/0.366203/0.356592. Source-calibrated 80% decision thresholds yielded varying final coverage; risk values at those unequal coverages cannot be interpreted as matched-coverage wins. All detailed proper scores, calibration, empirical conformal coverage and selective metrics are in `reports/results/router_prototype_3families.json`.

This is an exploratory **within-family** test on three previously held-out target settings. It is not a new-family router generalisation test, a full shift-aware router, or a statistically powered comparison. The router uses no explicit feature-distribution shift score. A nested leave-one-family-out or additional independent domains, followed by genuinely held-out meta-selection, is required before an adaptive improvement claim. Do not redesign this same prototype on the three final test outcomes.
