# Bank Marketing chronological holdout: preregistered protocol

Recorded 2026-10-20 before downloading or inspecting `bank-additional-full.csv` labels. Source: [UCI Bank Marketing dataset 222](https://archive.ics.uci.edu/dataset/222/bank+marketing), Moro, Rita and Cortez (2014), DOI 10.24432/C5K306; UCI lists CC BY 4.0. UCI describes `bank-additional-full.csv` as 41,188 rows ordered by date from May 2008 to November 2010. Order is the only chronology used. Month and weekday values are repeated calendar categories, not unique timestamps; no date is inferred from them or row number.

## Prediction point and schema

Predict whether a client subscribes a term deposit **before the current telephone call**. Target `y == yes`. Prespecified inputs: numeric `age`, `pdays`, `previous`; categorical `job`, `marital`, `education`, `default`, `housing`, `loan`, `contact`, `month`, `day_of_week`, `poutcome`. `pdays`, `previous` and `poutcome` describe previous campaigns and are assumed available before the current call. `contact`, `month` and `day_of_week` describe the scheduled/current contact and are assumed known when scheduling the call. We exclude `duration` because it is only known after the call; `campaign` because its definition includes the current contact and timing is ambiguous; and `emp.var.rate`, `cons.price.idx`, `cons.conf.idx`, `euribor3m`, `nr.employed` because their exact release availability at each call is not documented. The model receives no row index, inferred timestamp, client identifier or current-call outcome. This conservative 13-input protocol differs from papers using the full feature set.

## Split and locked analysis

For N=41,188 in original file order, use half-open index ranges: fit `[0,20594)` (50%); selection `[20594,26772)` (15% rounded down); calibration `[26772,30891)` (10% rounded down); near-future evaluation `[30891,35010)` (10% rounded down); final future test `[35010,41188)` (remainder, 15%). No random split or row shuffle. All preprocessing fits only on fit. Source selection minimises Brier over the fixed three- and five-expert sets. Independent calibration fixes split-conformal alpha 0.1. Evaluate near-future and final future only after choices are fixed; the former is **not IID**. The final segment's labels cannot alter features, model choice, thresholds or hyperparameters.

Report Brier, log loss, AUROC, AUPRC, accuracy, 10-bin ECE, split-conformal empirical coverage/set size and confidence-ranked risk–coverage/AURC for each future window; report selected-model fit time, inference time, total five-model fit cost and Windows peak process working set. A shared five-fit candidate comparison is equal-realised-compute; separately fit the three-model pool to report its actual smaller-pool cost and verify predictions. All five experts use the existing fixed configurations and seed 264738, one CPU thread, no tuning trials. Proper-score differences are descriptive for these ordered windows. Do not form row-IID confidence intervals or claim arbitrary future generalisation from one sequence. No reliable customer ID exists, so customer-disjointness cannot be guaranteed.

Prespecified exploratory baselines for later domain-held-out work: source-validation-selected fixed expert, uniform ensemble, source-validation-weighted ensemble, confidence-based expert choice and confidence-threshold abstention at source-calibrated coverage. Their decisions may use source-domain held-out predictions; neither near-future nor final future labels may tune them. A learned router remains gated on domain-held-out source evaluation and independently calibrated comparison.
